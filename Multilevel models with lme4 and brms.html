A motivating case

The linear mixed model

Linear mixed models extend the linear model: \[ y = X\beta + \epsilon \qquad \epsilon \sim N(0, \sigma) \] to: \[ \text{y} = \text{X}\beta + \text{Zb} + \epsilon \qquad\qquad \text{b} \sim \text{N}(0, \psi) \qquad\qquad \epsilon \sim \text{N}(0, \sigma) \] where the random vector \(b\) contains random effects, with zero expected value and covariance matrix \(\psi\), and \(Z\) is a model matrix for the random effects. The distributional assumption for b resembles the specification of a prior in Bayesian analysis, although the inferential framework is not Bayesian 1.

  1. Wood S. N., 2017. Generalized Additive Models An Introduction with R

The linear mixed model

When you include random factors, estimates at each level of the factor (i.e. for each subject) become informed by information at other levels (i.e. for other subjects). Rather than estimating the intercept and slope for each participant without considering the estimates for other subjects, the model estimates values for the population, and pulls the estimates for individual subjects toward those values, a phenomenon called “shrinkage”.
The level 1 of the model is: \[ Y_{sd} = \beta_{0s} + \beta_{1s} X_{sd} + e_{sd} \] the level 2 is: \[ \beta_{0s} = \gamma_{0} + S_{0s} \\ \beta_{1s} = \gamma_{1} + S_{1s} \] and the variance components are: \[ \langle S_{0s}, S_{1s} \rangle \sim N\left(\langle 0, 0 \rangle, \mathbf{\Sigma}\right) \\ \mathbf{\Sigma} = \left(\begin{array}{cc}{\tau_{00}}^2 & \rho\tau_{00}\tau_{11} \\ \rho\tau_{00}\tau_{11} & {\tau_{11}}^2 \\ \end{array}\right) \\ e_{sd} \sim N\left(0, \sigma^2\right) \] Random effects \(S_{0s}\) and \(S_{1s}\) allow intercepts and slopes, respectively, to vary over subjects. These random effects are deviations from the population ‘grand mean’ values 1.

  1. Barr, Dale J. (2021). Learning statistical models through simulation in R An interactive textbook. https://psyteachr.github.io/stat-models-v1

The linear mixed model

When multiple observations are made within groups, each group is different but helps us make an estimate for the other groups. If we ignore the groups and assign the same intercept to each of them, we’ll likely ignore important variation. We may estimate a unique intercept for each cluster: \[ y \sim \text{Binomial}(n, p) \qquad\qquad \text{logit}(p) = \alpha_\text{group} \qquad\qquad \alpha_\text{group} \sim \text{Normal}(0,1.5) \] but then we would be moving from one group to another as they were completely independent. With a mixed model, we simultaneously estimate both an intercept for each group and the variation among them. As before, we assign a different intercept to each group, but now we also learn what is common to all of these intercepts: \[ y \sim \text{Binomial}(n, p) \qquad\qquad \text{logit}(p) = \alpha_\text{group} \qquad\qquad \alpha_\text{group} \sim \text{Normal}(\bar{\alpha},\sigma) \\ \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad \bar{\alpha} \sim \text{Normal}(0, 1.5) \\ \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad \sigma \sim \text{Exponential}(1) \] Mixed models are often referred to as multilevel models. The two parameters \(\bar{\alpha}\) and \(\sigma\) inside \(\alpha_\text{group}\sim\text{Normal}(\bar{\alpha},\sigma)\) is where the “multi” in “multilevel” arises. The Gaussian distribution with mean \(\bar{\alpha}\) and standard deviation \(\sigma\) is the prior for the intercept of each groups. But that prior itself has priors for \(\bar{\alpha}\) and \(\sigma\). So there are two levels in the model, each resembling a simpler model1.

  1. McElreath R., 2020. Statistical Rethinking A Bayesian Course with Examples in R and STAN

Partial pooling: brms

library(brms)

priors <- c(
  # Population-level intercept, expected reaction time at day zero
  prior(normal(265, 29), class = "Intercept"),

  # Population-level slope, expected response change per day
  prior(normal(12, 9), class = "b", coef = "Days"),

  # Between-subject sd of varying intercepts
  prior(normal(0,29), class = "sd", group = "Subject", coef = "Intercept"),

  # Between-subject sd of varying slopes
  prior(normal(0,9), class = "sd", group = "Subject", coef = "Days")
)

pp_model_bys <- brm(
  formula = Reaction ~ Days + (Days | Subject),
  data = sleepstudy,
  family = gaussian(),
  prior = priors,
  sample_prior = "yes",
  chains = 5,
  iter = 4000,
  warmup = 2000,
  cores = 5,
  seed = 123
)
